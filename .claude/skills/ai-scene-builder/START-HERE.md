# AI Scene Builder

Start with [installation and first run](references/installation.md).

Included: a reusable agent skill, bedroom visual reference, scene/lighting/motion guides, and two Blender helpers. No video or prior chat is needed.

For Codex or Claude Code, extract this folder into the appropriate skills location. For Claude custom Skills, upload the ZIP itself. Setup details and a ready-to-paste starting request are in the guide.

The helpers have been tested with Blender 4.5.2 on Windows. Claude installation follows its documented format; it has not been execution-tested inside Claude. This is a guided workflow, not a one-click replica of the reference room. The finished Blender scene is a separate download.
