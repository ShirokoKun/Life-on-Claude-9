# How this is built

Everything in the room — geometry, textures, lighting — is generated by code. No model files, no
image textures, no HDRIs.

## Pipeline in one paragraph

`src/scene/*` builds the room as ordinary three.js meshes. Lighting is **not** real-time lights:
`src/bake` path-traces sky light entering through the window on the CPU (web workers +
`three-mesh-bvh`) and stores irradiance **per vertex** (`gi`, `gd`, optional `giB` attributes) in
`public/bake/gi.bin`. Materials are normal `MeshStandard/PhysicalMaterial`s patched (`core/gi.js`)
to read those attributes, plus a box-projected PMREM capture of the room for specular.
`src/render/pipeline.js` adds contact AO, bloom and the grade; offline renders average jittered
sub-frames for anti-aliasing, lens depth of field and motion blur.

## Coordinates (metres)

- X runs along the window wall (0 … 4.8), Z runs into the room (window wall at z = 0, back wall at
  z = 4.0), Y is up (ceiling 2.5). Outside is z < 0. The wall is 0.32 thick.
- Window opening: x 0.55–2.45, y 0.86–2.26. Sill board top y = 0.862, x 0.5–2.5, z −0.145 … +0.045.
- See `src/scene/layout.js` for furniture footprints.

## Writing a part

A part is a file in `src/scene/parts/` that exports:

```js
export const order = 20;          // load order (deterministic!)
export const label = 'bed';       // shown while loading
export function build(ctx) { … return group; }   // THREE.Group, world-space metres
```

`ctx.M` is the shared material library (`scene/materials.js`), `ctx.colliders.push({min:[x,y,z],max:[x,y,z]})`
registers a walk-collision box, `ctx.animated.push((t)=>{…})` registers a per-frame callback.

Rules that keep the baked lighting valid:

1. **Deterministic**: all randomness through `new RNG(seed)` from `core/rng.js`. Never `Math.random()`.
2. **Materials** must come from `pbr(params, extra)` / `fabric(color, opts)` in `scene/materials.js`
   (or `ctx.M.*`). They are lit only by the bake; a plain three material renders black.
   Colours: `sc(r,g,b)` takes sRGB values. For textured materials pass
   `extra.bake = { albedo:[r,g,b] }` (linear average) so bounce light has the right colour.
3. **Tessellate** — light is stored per vertex, so big flat faces need vertices:
   `roundedBox(w,h,d,{r, rs, maxEdge})`, `gridPlane(w,h,maxEdge)` from `core/geo.js`.
   Use `maxEdge` 0.015–0.02 where objects rest on a surface (table tops, shelves), 0.04–0.06 for large
   furniture faces, default for small props. Every box should have a bevel (`r` ≥ 1.5 mm).
4. Thin things lying flat on a wall/floor (posters, rug) set `mesh.userData.bakeOccluder = false`
   so they don't carve a dark halo into the surface behind them.
5. Translucent cloth / leaves: `fabric(color, { trans: 0.3, side: THREE.DoubleSide })` or
   `pbr(params, { back: true, trans: new THREE.Color(…) })` with
   `mat.userData.bake = { albedo, trans: 0.3, transColor, twoSided: true, thru: 0.0 }`
   (`trans` = diffuse transmission probability, `thru` = fraction of rays passing straight through,
   for sheers / leaf cards with holes).
6. Lots of small identical things (leaves): one `InstancedMesh` with `mesh.userData.giInstanced = true`
   → one light sample per instance (set `userData.giNormal` / `giAnchor` in the instance's local space).
7. Not lit by the bake (sky dome, glass, emissive): `mesh.userData.gi = false`; not a shadow caster:
   `material.userData.bake = { ignore: true }`.
8. Wind / motion happens in the vertex shader through `pbr(…, { onCompile(shader){…}, key:'unique' })`
   using the shared `uTime` uniform (`GI.uniforms.uTime`, seconds). Rest pose is what gets baked.

## Tools

```
npm run dev                                   # http://127.0.0.1:5319
node tools/shot.mjs bed wide                  # screenshots of named cameras -> shots/*.jpg
node tools/shot.mjs 1.2,1.4,2.5,1.5,1.0,0,45  # custom camera: pos xyz, target xyz, fov
node tools/shot.mjs --bake 256                # re-bake lighting -> public/bake/gi.bin
node tools/shot.mjs --bake 32 --workers 3 --url "only=bed&out=public/bake/tmp_bed.bin" bed
                                              # work on one part in isolation (room shell + that part)
node tools/film.mjs                           # render the film
```
