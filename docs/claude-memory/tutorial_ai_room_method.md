Core order: grey shell in metres -> one hero light-shaping object (blinds) -> per-asset decision: script hard-surface, generate (Tripo) organic/soft, repair failed detail by script -> dress big to small in clusters -> grey pass then materials with wear -> light in layers (sky, practicals, sun) -> volumetric atmosphere -> alternate night rig on same geometry -> operated/handheld camera.
